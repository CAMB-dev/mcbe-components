## 输入与基线

固定目标是已有 GUI5 建筑分类十条配方，2570×1402、3,603,140个RGBA像素。A保留 D 的十四张完整原图、显式图集位置及三个完整双cuboid阶梯。E只把 index3 改为原玻璃板 B 的薄Z盒与对应面材质：五处JSON叶差异，其他输入相同。

两臂在启动浏览器前一起冻结。旧 D 留下的161项pin中有14项源码已变化，因此本轮明确记录漂移，重新冻结当前1,174项源／资源／夹具身份；没有将旧pin回填为“仍未改变”。先运行当前 A，其完整RGBA SHA256仍逐字节等于旧 D 的 `a09c800449f075fb84e58723f47e97372d9e415ec2b8b4b4e7df95993386727a`，才运行 E。

实际浏览器后端为 NVIDIA RTX3050 Laptop／ANGLE D3D11，DPR1。每臂先验证独立原生简单拷贝完整零差，随后绘制真实组件；source图层、三种右侧模型、六张物品图和十条配方接管标记均核对。运行错误、HTTP失败和前后pin变化为空；浏览器与5495服务均关闭，保留用户4173。

A→E有2,188个像素改变：1,453个旧误差变精确，**2个原精确像素新增误差**，733个双方仍错但数值改变。净减少1,451个不同像素，不称“所有改动都改善”。单元外3,595,040个像素的A/E RGBA逐字节不变；它们仍包含680个原生残差，不能将“补集未变”说成“补集与原生零差”。

历史玻璃板 B 独立实验的单元残差为1,416，E为1,417。它们的图集表示不同，两个历史改善数不能直接相加，也不能把组合结果改记成1,416。阶梯、完整方块、玻璃板和放大镜仍有残差；图集位置、相机、字体和布局是明确的有限宿主输入，没有由单一目标恢复通用原生默认规则。

原始 A／E／native PNG均完整保留。没有更改旧目标、裁掉评分区域、移动UV、添加像素修补、放宽误差阈值或按结果再调候选。初次运行器因同步子进程阻塞自身Vite事件循环而超时；该失败保留，改用异步子进程后执行同一冻结输入，未因此改变图像数据。

新增仓库工具使用Python标准库独立解析PNG的chunk CRC、deflate与五种行filter；不依赖浏览器、PNGjs、Pillow或NumPy。它重新检查原目标及简单拷贝、实际输出RGBA身份、源pin、真实后端、接管标记、冻结输入及允许的单元输入差异，再评分整幅目标。

```powershell
python -m unittest discover -s tests -p crafting_candidate_audit_test.py -v
python scripts/compare-crafting-candidates.py --study .cache/crafting-model-combined-20261103-01 --output .cache/crafting-model-combined-20261103-01/my-audit --region 790 392 90 90
```

需要Python3.10+及本机已有私有采集、冻结输入和实际运行报告；这些不随Git/npm分发。缺失／漂移明确失败，不创建替代golden。输出目录必须是新目录。`--region`只分类变化，无法排除主评分像素。工具的六项检查通过，包括五个独立PNGjs冻结编码、CRC／截断／格式／预算拒绝及RGBA／alpha计数；完整原生目标也由标准库重新解码，所得结果与浏览器运行报告逐项相同。

本轮没有库／demo／package manifest变更，不重记上一轮React18／19或安装矩阵为新执行。私有证据位于 `.cache/crafting-model-combined-20261103-01/`，包含 FROZEN、EXECUTION02、完整输出、cpu-redecode02、原失败及阶段FINAL。E是一次已执行、仍非零的组合实验，未提升为默认样式或完整GUI认证。
