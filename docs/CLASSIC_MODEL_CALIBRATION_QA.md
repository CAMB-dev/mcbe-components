# Classic模型校准验证

本阶段冻结一组共用校准参数，并将它用于真实`CraftingScreen`，与旧参数作完整原生目标比较。两个基线分别逐字节重现前阶段GUI5 E和GUI4保留场景，门禁通过后才执行对应校准臂。另检查Compact和空筛选页与既存完整结果逐字节相同。

| 场景 | 旧参数不同像素 | 校准后不同像素 | 本次变精确 | 新增误差 |
| --- | ---: | ---: | ---: | ---: |
| GUI5建筑页 | 2,097 | 1,422 | 675 | 0 |
| GUI4建筑页 | 1,419 | 1,078 | 341 | 0 |
| GUI4 Compact | 0 | 0 | 0 | 0 |
| GUI4空筛选 | 160 | 160 | 0 | 0 |

六次实际产品绘制每次评分全部3,603,140个RGBA像素，alpha差异均为0。实际适配器为NVIDIA RTX3050／ANGLE D3D11、DPR1；原生复制显示六次均为0，所有产品标记／源pin／运行异常门禁通过。Compact与空筛选的校准画面还分别与历史完整产品RGBA逐字节一致。

Python标准库独立解码全部六份输出和各原生目标，重新核对PNG CRC、RGBA身份、像素／字节／alpha计数及完整A→B变化。GUI5实际只改变675个像素，GUI4只改变341个，全部变为原生精确值；没有“双方仍错但改变”的像素。源布局单元分类表明，两种比例的九个非玻璃板模型单元均零差；玻璃板保持1,417／918点，单元外放大镜保持5／160点，未掩盖这些残差。

参数在`FROZEN.json`中于新GPU评分前确定，为三份旧约束区间交集的中点。公开只读配置的运行时对象实际送入正常模型构造。它是有限参考校准；数据来自已观察画面，不声称blind发现或原生引擎常数。原生顶点、矩阵、资源ID和捕获纹理不作为生产输入。具体范围见[API说明](CLASSIC_MODEL_CALIBRATION.md)。
