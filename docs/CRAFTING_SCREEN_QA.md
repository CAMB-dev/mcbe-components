# Classic 工作台与配方书

2026-10-29，Minecraft for Windows `1.26.6005.0`，公开来源为 Mojang `v1.26.60.5` full release，固定 commit `15701fa9c13923f12662984c32c124327e40e3d3`。库的基准是 GUI2；原生工作台采样是 GUI5、100%、AA16。本文区分原始声明、浏览器组件验证与原生观察，未认证完整原生 RGBA 零差。

新增 `CraftingScreen`、`RecipeBook`、`RecipeBookEntry`、`RecipeFilterToggle`。旧 `CraftingTable` 保留独立右面板 API。完整组合复用它及已有分类标签、搜索、滚动、背包格和原版双模式工具栏。配方查询、分类集合、可合成标志、分组展开与合成结果由宿主提供。

来源研究独立解析了九份本机/公开 JSON，完整 parsed 对象一致；保留97个原始控件定义、行号和62张原图的来源与哈希。证据在本地 `.cache/crafting-recipe-study/{SOURCE_PLAN.md,source-facts.json}`，研究阶段未使用生产 CSS 生成期望。可分发的来源、几何与原生截图哈希摘要见 [crafting-screen-geometry.json](crafting-screen-geometry.json)。新增九张可分发皮肤逐字节等于公开 ZIP 和本机原图，未解码重编码，见 [recipe-book-textures.json](recipe-book-textures.json)。它们包括分组背景、红色背景、7×7分组角标及选中框。

## 原生观察

只在专用 `mcbeui GUI Reference` 世界以 `setblock ... keep` 向空位放置一张工作台，并切换自身生存模式采样。使用游戏窗口 Alt+Print，经 Paint 另存 PNG，不使用工具返回的 JPEG 作为颜色基准。

搜索生存布局原图 `.cache/tooltip-native/crafting-search-survival-gui5.png`，2568×1400，SHA256 `d4904aafcff21d10b0f952638d57af22d2da7f3a599913889435c2d19f50f7bf`。独立测量得到根起点[476,282]、左730物理像素、书脊20、右880，总1630=326×5；搜索框[506,377,520,80]；列表[506,467,670,615]，七列首格x526、步长90，左右各20物理像素。该原图无滚动条，与源134宽视口内七列居中相符。

筛选的27×15原图落在[1041,380,135,75]，源半像素y经GUI5栅格化不能反推为新的逻辑offset。既有文字、半透明阴影与边缘采样残差仍保留；新的左侧x506边缘也在旧全局phase训练范围之外，不能把旧拟合外推到全屏。更多状态及独立结果继续保存在 `.cache/crafting-native-independent/`。

其余三张原图按各自哈希独立核对：收起布局右面板[851,282,880,830]，相对固定根[476,282]为x75game；工具栏[1236,182,495,100]的右端对应x251game。建筑分类不绘制搜索框，原搜索框顶边区域2600像素全为面板灰198；列表改为[506,387,670,695]，即源y21/h139。筛选可见原图[1041,305,135,75]符合源按钮y3.5及居中图像y4.5的半像素栅格化。开启“仅可合成”后，同列表无红格或物品，顶部10行阴影47、主体93。这些是已观察状态的局部几何与颜色，不是隐藏命中框、配方规则或完整画面认证。

## 验证边界

浏览器原PNG组合、源坐标、受控数据、意图回调、选中状态、滚动、焦点与移动端局部横滚分别验证。键盘网格导航与HTML输入caret/IME属于Web交互适配；源中残留的armor focus目标没有伪造为“工作台左边缘跳到配方书”。展示页只有小型演示数据集，不含Minecraft配方数据库。

正式 `tests/crafting-screen.spec.ts` 的23项最终通过；默认及六种宿主背景、两个分组角标和选中外扩区域使用原PNG独立合成，完整52×52区域RGBA零差，无mask或容差。独立首次测试曾将滚动条命中区和绘制轨道混用，修正为分别验证6game与4game，未改生产或放宽像素断言。禁用右/中键、Home/End跳过禁用边界均有回归；默认可访问名称包含实际显示的可合成数量，零数量不增加可见角标。

源及原图几何之外，独立原生局部模型仍保留非零差异：完整筛选图加2物理像素halo共10981像素，硬源图840像素差；既有冻结phase诊断后仍295像素差、最大1。空3×3格同诊断后仍240像素差、最大1；搜索字段仍361像素差、最大5。部分局部结果/帮助/关闭/书脊中段模型零差只属于该诊断，未进入生产，也不认证完整screen。左侧x506的旧phase外推为负权重，是明确的范围外反例。

完整原生像素、引擎背景选择/自动空间导航、手柄辅助及Pocket仍待验收。测试通过不消除字体/书本的独立非零残差。
