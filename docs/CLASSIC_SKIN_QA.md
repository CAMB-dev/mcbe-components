# Classic 九宫格重叠切片

原版 `disabledButton.png` 是完整3×3图像，原始元数据却声明每边切片2。切片重叠时，中心源跨度为负；旧实现把负值写入 CSS `background-size`，浏览器因此丢弃该尺寸。此次保留原图和元数据，将非正中心跨度按已有 POINT 路径的边界像素策略处理。

重叠切片还可能出现整数目标盒配上小数背景绘制尺寸，例如3像素原图在3像素目标盒中显示2像素切片，背景实际需要4.5像素。浏览器会独立取整，因此这些重叠场景改走既有的逐源像素分段路径。非重叠材质的原路径保持不变。该策略是有限 Web 解释，不宣称恢复了原生重叠切片求值器。

验证结果：

- Node 回归首次1项通过、2项失败；修复后3项通过。
- Chromium 的36个完整 RGBA 平面对照全部零差，包含完整原版图、独立非对称测试图、压缩尺寸及1／2／3倍缩放。首阶段有两个压缩案例分别差10／2像素；失败保留，第二阶段只修产品，预期图像身份未变。浏览器已关闭。
- 独立 CPU 审阅覆盖4112组 SSR：3744组非负中心输入旧新 HTML 完全相同，368组负中心输出均有限有效。实际 Portfolio／Invite 的117组结果为111组相同、6组预期修复变化；源 PNG／元数据身份和跨度／补片预算通过。
- 源码、demo 类型检查和完整构建通过。此记录不替代实际安装包、Chat 整页或原生 GUI 验收。
