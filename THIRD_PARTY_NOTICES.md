## MCBE Pixel (modified Monocraft)

- Based on the Monocraft v4.2.1 regular font above; same SIL OFL 1.1 license and copyright.
- Renamed family: MCBE Pixel. Original outlines and advance widths are preserved.
- Modification: duplicate outline glyphs as COLR v0 foreground layers (`paletteIndex=0xFFFF`) to avoid ClearType color fringes in the tested Chromium renderer. Generated by `scripts/prepare-pixel-font.py`.
- Bundled file: `dist/fonts/MCBEPixel-Regular.woff2`, 44,304 bytes.
- WOFF2 SHA256: `63afb50e1a41962f939ffad9df43f0f9047ccfe9f7daedb0b64612a074161c2f`.

## MCBE CJK (modified Fusion Pixel)

MCBE CJK is a renamed derivative of Fusion Pixel Font 2026.10.25, under the same SIL OFL 1.1 license and inherited notices listed above. ## Visual reference

Mojang's official Bedrock sample assets were examined for color, bevel and nine-slice references. The ignored `.cache/references` cache and standalone diagnostic references are not distributed as such; this is not a blanket exclusion of original game images. The package also embeds or bundles specific original PNG resources described below. Classic skin source paths, encoding and hashes are recorded in `docs/classic-skins.json`; reconstructed reference skins and unchanged source images retain their applicable upstream rights and are not relicensed as original artwork by this project's MIT license.

- Reference: https://github.com/Mojang/bedrock-samples
- Pinned commit: `46ba6ea985fb5a92d79a9419198f10dda14c199d`.
- Upstream license: https://github.com/Mojang/bedrock-samples/blob/46ba6ea985fb5a92d79a9419198f10dda14c199d/LICENSE.md

No Mojangles font or native game screenshot is bundled in the npm library. The optional local Vite preview may load a Mojangles.ttf copied from the user's own game installation into the ignored `.cache/local-fonts` folder, or its renamed Mojangles Pixel COLR wrapper; a site build made with that file present also embeds it. The wrapper preserves the original outlines and metrics and does not change ownership or licensing. That local font is a separately owned game asset and is not covered by this project's licenses. The demonstration voxel island, branding grass block and the 16 legacy PixelIcon SVG symbols are original project illustrations; the separate GuiIcon catalog below contains original game PNG artwork. This is an independent fan project and is not affiliated with or endorsed by Mojang or Microsoft.

The local HBUI preview can also register unchanged Minecraft Ten v2, Minecraft Seven v2 and the installed Noto Sans SC OpenType files from ignored `.cache/local-fonts/hbui`. The optional preparation script does not copy those font binaries into source, public or npm directories. Their identity metadata is recorded in `docs/local-hbui-fonts.json`; original ownership and applicable font licenses remain separate. An enabled local site build can embed them, just as it can embed local Mojangles. The npm package continues to ship only the open WOFF2 fonts documented above.

The optional native HBUI loading indicator GIF also stays in ignored local cache and local preview, outside Git/public/npm. Its source identity is metadata-only in `docs/local-hbui-fonts.json`. The default world-modal LoadingScreen separately embeds the unchanged official sample `title.png` Minecraft branding and original loading-bar images in its texture CSS; this source-derived artwork retains Mojang's upstream ownership and is documented in `docs/system-screens-geometry.json`. The caller can override `branding` or pass `branding={null}`.

## Actual game materials and renderer resources

The demonstration now uses actual raster item resources rather than original item illustrations. The original voxel island and branding block remain project illustrations. The twenty-six PNGs listed in `docs/item-materials.json` are unchanged resources from the official `v1.26.60.5-full` merged release, stored under `demo/assets/minecraft`. Their SHA256, sample source paths, and matching installed base/overlay candidates from 59 vanilla resource directories are recorded in schema 2 of that manifest. Those files are demo-only and excluded from the npm package. The diamond sword uses the 198-byte merged-release image; the earlier 22-pixel difference describes base-pack versus merged images and does not establish which resource the running game selects. Candidate presence and manifest metadata do not prove runtime activation or pack precedence.
