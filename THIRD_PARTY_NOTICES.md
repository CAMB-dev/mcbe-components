## MCBE Pixel (modified Monocraft)

- Based on the Monocraft v4.2.1 regular font above; same SIL OFL 1.1 license and copyright.
- Renamed family: MCBE Pixel. Original outlines and advance widths are preserved.
- Modification: duplicate outline glyphs as COLR v0 foreground layers (`paletteIndex=0xFFFF`) to avoid ClearType color fringes in the tested Chromium renderer. Generated by `scripts/prepare-pixel-font.py`.
- Bundled file: `dist/fonts/MCBEPixel-Regular.woff2`, 44,304 bytes.

## MCBE CJK (modified Fusion Pixel)

MCBE CJK is a renamed derivative of Fusion Pixel Font 2026.10.25, under the same SIL OFL 1.1 license and inherited notices listed above. It preserves all outlines, Unicode mappings and advance widths, adding COLR v0 foreground layers that reference the existing outline glyphs. It is bundled as `dist/fonts/MCBECJK-12px-zh-hans.woff2`; provenance, size and SHA256 are recorded in `docs/pixel-cjk-font.json`. The unchanged upstream Fusion Pixel file remains available separately.

## Visual reference

Mojang's official Bedrock sample assets were examined locally for color and bevel measurements. Their original image files are excluded from the package (`.cache/references` is ignored). The package includes reconstructed pixel skin PNGs embedded in CSS, generated from measured color runs and nine-slice metadata; provenance and hashes are recorded in `docs/classic-skins.json`. These reference-derived visuals remain subject to applicable upstream rights and are not relicensed as original artwork by this project's MIT license.

- Reference: https://github.com/Mojang/bedrock-samples
- Pinned commit: `46ba6ea985fb5a92d79a9419198f10dda14c199d`.
- Upstream license: https://github.com/Mojang/bedrock-samples/blob/46ba6ea985fb5a92d79a9419198f10dda14c199d/LICENSE.md

No Mojangles font or native game screenshot is bundled in the npm library. The optional local Vite preview may load a Mojangles.ttf copied from the user's own game installation into the ignored `.cache/local-fonts` folder, or its renamed Mojangles Pixel COLR wrapper; a site build made with that file present also embeds it. The wrapper preserves the original outlines and metrics and does not change ownership or licensing. That local font is a separately owned game asset and is not covered by this project's licenses. The demonstration voxel island, branding grass block and 16 pixel icons are original project illustrations. This is an independent fan project and is not affiliated with or endorsed by Mojang or Microsoft.

The local HBUI preview can also register unchanged Minecraft Ten v2, Minecraft Seven v2 and the installed Noto Sans SC OpenType files from ignored `.cache/local-fonts/hbui`. The optional preparation script does not copy those font binaries into source, public or npm directories. Their identity metadata is recorded in `docs/local-hbui-fonts.json`; original ownership and applicable font licenses remain separate. An enabled local site build can embed them, just as it can embed local Mojangles. The npm package continues to ship only the open WOFF2 fonts documented above.

The optional native HBUI loading indicator GIF also stays in ignored local cache and local preview, outside Git/public/npm. Its source identity is metadata-only in `docs/local-hbui-fonts.json`. The default world-modal LoadingScreen separately embeds the unchanged official sample `title.png` Minecraft branding and original loading-bar images in its texture CSS; this source-derived artwork retains Mojang's upstream ownership and is documented in `docs/system-screens-geometry.json`. The caller can override `branding` or pass `branding={null}`.

## Actual game materials and renderer resources

The demonstration now uses actual raster item resources rather than original item illustrations. The original voxel island and branding block remain project illustrations. The twenty-six PNGs listed in `docs/item-materials.json` are unchanged resources from the official `v1.26.60.5-full` merged release, stored under `demo/assets/minecraft`. Their SHA256, sample source paths, and matching installed base/overlay candidates from 59 vanilla resource directories are recorded in schema 2 of that manifest. Those files are demo-only and excluded from the npm package. The diamond sword uses the 198-byte merged-release image; the earlier 22-pixel difference describes base-pack versus merged images and does not establish which resource the running game selects. Candidate presence and manifest metadata do not prove runtime activation or pack precedence.

The Image / NineSlice demo fixture also embeds four unchanged Mojang control PNG references. Their hashes, original source URLs and full-release metadata are recorded in `docs/image-geometry.json`; they are not original project artwork or MIT-licensed replacements. The fixture remains demo-only.

The optional `EnchantingBook` component includes Mojang's unchanged `resource_pack/textures/entity/enchanting_table_book.png`, SHA256 `e8d23533b48976b578098db767e2c8161a31fa5d7b22bf576bf531b1bc7f000f`, from the pinned sample commit above. The upstream notice is retained in `dist/assets/Minecraft-Sample-LICENSE.md`. It remains a Mojang asset subject to its upstream terms, not original MIT artwork. Its WebGL mesh/camera is a project reconstruction and is not claimed to match the native renderer.

`EnchantingRunes` requires a caller-owned SGA atlas. The original `font/ascii_sga.png` is only copied into ignored local preview storage and is excluded from npm and Git. Its source and pixel sampling evidence are recorded in `docs/enchanting-renderer.json`.

`BitmapText` also requires caller-owned atlas pages and explicit glyph metrics. The optional `scripts/use-local-unicode-sample.py` prepares only eight unchanged installed Unicode pages and a ten-character sample in ignored `.cache/local-fonts/unicode`; these are not bundled in Git, public source assets or npm. A local Vite `site/` build with the sample enabled can include those pages. Source identities, measured geometry and unresolved native coverage are recorded in `docs/native-bitmap-font.json`; the component's sampling/compositing code does not change the ownership or licensing of supplied font artwork.

The HUD components embed unchanged Mojang PNG resources in `dist/hud-textures.css` and `dist/hud-overlay-textures.css`, including status glyphs, hotbar cells, experience layers, boss-bar layers, tooltip backgrounds and the `icons.png` atlas. Per-resource provenance, hashes and native source declarations are recorded in `docs/hud-geometry.json` and `docs/hud-overlays-geometry.json`. These are Mojang assets subject to the upstream terms, not original MIT artwork. Native custom-renderer behavior and full-frame equivalence are separate from resource-byte verification.

The advanced workstation components embed thirty-one unchanged Mojang PNG resources in `dist/advanced-workstation-textures.css`. Their source paths, hashes and matching installed/public-release references are recorded in `docs/advanced-workstation-textures.json`. They remain subject to the same upstream rights; native banner, block and item renderers are distinct from these control images.

The feedback components embed six unchanged Mojang PNG resources in `dist/feedback-textures.css`, including the native loading atlas, tooltip background, toast border and light close-button states. Source paths, hashes and fixed public URLs are recorded in `docs/feedback-geometry.json`. Their artwork remains subject to the upstream terms; Web positioning, focus and notification lifetime are project code.

The settings controls embed five unchanged Mojang PNG resources in `dist/settings-control-textures.css`. Source paths, hashes, fixed URLs and installed-game comparisons are recorded in `docs/settings-controls-geometry.json`. Search/navigation artwork retains the upstream ownership independently of the project's input, key-capture and form code.

The inventory panes, trading/mount panes, game controls, game lists and system-screen compositions embed original Mojang control images in their respective texture CSS files. Asset hashes, original paths, fixed public URLs and source-layout boundaries are recorded in `docs/inventory-screens-geometry.json`, `docs/trading-mount-textures.json`, `docs/game-controls-geometry.json`, `docs/game-lists-geometry.json` and `docs/system-screens-geometry.json`. These source-derived visuals retain the upstream rights. The two game-control demonstration images (Minecraft title and generic gamer picture) are separately listed under `demoAssets` in `docs/game-controls-geometry.json`, stored only in the demo directory and excluded from the npm package.

`BlockPreview` and `BannerPreview` include forty-five unchanged official block/banner PNG and TGA assets under `dist/assets/item-renderers`. Their original byte hashes and installed resource candidates are recorded in `docs/item-renderers-geometry.json`; the full-release license is copied unchanged to `dist/assets/item-renderers/LICENSE.md`. TGA decoding retains the original alpha values. The mesh, camera, tint presets, software rasterizer and item lighting are project reconstructions, not a redistribution or certification of the native renderer. The exposed dye palette is a Web profile; the 32-entry loom ordering records a specific native capture rather than a universal engine registry.

`ItemGlint` includes the unchanged official `resource_pack/textures/misc/enchanted_item_glint.png` under `dist/assets/glint`, together with the original upstream `LICENSE.md`. Source identity and formula boundaries are recorded in `docs/item-glint-geometry.json`. The original texture retains Mojang's upstream ownership. The raw shading helper and CPU compositing helper are project implementations of the recovered UIGlint formula with caller-supplied uniforms, sampler and blend factors; they do not authenticate a native draw state, clock, default tint or pixel-perfect result. Private native shader binaries and screenshots are not shipped in the npm package.
