## MCBE Pixel (modified Monocraft)

- Based on the Monocraft v4.2.1 regular font above; same SIL OFL 1.1 license and copyright.
- Renamed family: MCBE Pixel. Original outlines and advance widths are preserved.
- Modification: duplicate outline glyphs as COLR v0 foreground layers (`paletteIndex=0xFFFF`) to avoid ClearType color fringes in the tested Chromium renderer. Generated by `scripts/prepare-pixel-font.py`.
- Bundled file: `dist/fonts/MCBEPixel-Regular.woff2`, 44,304 bytes.
- WOFF2 SHA256: `63afb50e1a41962f939ffad9df43f0f9047ccfe9f7daedb0b64612a074161c2f`.
- Full license: `dist/fonts/Monocraft-OFL.txt`. This is an open substitute, not Mojangles.

## MCBE CJK (modified Fusion Pixel)

MCBE CJK is a renamed derivative of Fusion Pixel Font 2026.10.25, under the same SIL OFL 1.1 license and inherited notices listed above. It preserves all outlines, Unicode mappings and advance widths, adding COLR v0 foreground layers that reference the existing outline glyphs. It is bundled as `dist/fonts/MCBECJK-12px-zh-hans.woff2`; provenance, size and SHA256 are recorded in `docs/pixel-cjk-font.json`. The unchanged upstream Fusion Pixel file remains available separately.

## Visual reference

Mojang's official Bedrock sample assets were examined locally for color and bevel measurements. Their original image files are excluded from the package (`.cache/references` is ignored). The package includes reconstructed pixel skin PNGs embedded in CSS, generated from measured color runs and nine-slice metadata; provenance and hashes are recorded in `docs/classic-skins.json`. These reference-derived visuals remain subject to applicable upstream rights and are not relicensed as original artwork by this project's MIT license.

- Reference: https://github.com/Mojang/bedrock-samples
- Pinned commit: `46ba6ea985fb5a92d79a9419198f10dda14c199d`.
- Upstream license: https://github.com/Mojang/bedrock-samples/blob/46ba6ea985fb5a92d79a9419198f10dda14c199d/LICENSE.md

No Mojangles font, Minecraft logo or game screenshot is bundled in the npm library. The optional local Vite preview may load a Mojangles.ttf copied from the user's own game installation into the ignored `.cache/local-fonts` folder, or its renamed Mojangles Pixel COLR wrapper; a site build made with that file present also embeds it. The wrapper preserves the original outlines and metrics and does not change ownership or licensing. That local font is a separately owned game asset and is not covered by this project's licenses. The demonstration voxel island, grass block, item illustrations and 16 pixel icons are original project illustrations.
