# Installed FileTransmission contracts

The helper uses an already-installed peer and writes only its
file-transmission-contracts child directory. The three-font profile and measured
widths/warning-height are authored Web fixtures; there are no hidden Progress
defaults. The host explicitly supplies the Screen's unresolved base/title nodes.

The typed consumer exercises all three forwarded public components with actual
key/ref metadata, callbacks, exact source enums and logical controller IDs.
The worker checks actual installed ESM/SSR behavior, independent visibility
branches, early failures, no SSR side effects, the ten complete source PNGs and
available raw metadata/copyright, and CSS bytes with recursive dependencies.
It does not install dependencies, run a server/browser, test backend transfer,
or claim native layout/font/material qualification. Root owns those other gates.
