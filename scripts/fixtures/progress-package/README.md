# Installed Progress contracts

The verifier copies model.ts and consumer.tsx into an already-installed peer's
progress-contracts child directory. The fixture uses explicit authored Web font,
intrinsic, clip, platform branding and missing-material choices. Embedded host
PNG inputs remain whole originals; this is not native provider/font recovery.

The consumer checks all six public components, source enums, callbacks, refs and
the logical controller API with strict positive and expected-negative types.
The worker uses the consumer's actual React/UI installation for ESM and SSR,
checks source-registered routes/gates and concrete public parts, latent preflight,
source material/metadata/license identities, CSS export/dependency bytes and no
relocatable asset URLs. It never installs, starts a server or opens a browser.

Default-Vite development/production mounted acceptance and native visual
qualification are separate root-owned gates. This helper does not claim them.
